# AI Stress Analyzer

The AI Stress Analyzer is an interactive, React-based web application designed to help users monitor, understand, and manage their stress levels. By combining questionnaire-based assessments with contextual analysis (such as evaluating communications and interactive chat), the application provides a personalized, holistic view of a user's mental well-being.

## Motivation

In today's fast-paced digital world, chronic stress is a growing concern that affects personal health and professional productivity. Traditional methods of tracking stress are often static, reactive, and lack the ability to analyze real-time context.

The AI Stress Analyzer was built to bridge this gap. The goal is to create a tool that not only asks the right questions but also understands the user's environment by offering an interactive conversational interface and parsing potential daily stressors. The primary goals of this project are:
*   **Proactive Awareness:** To give users real-time visibility into their stress levels before they lead to burnout.
*   **Contextual Understanding:** To analyze specific triggers to provide highly relevant, personalized feedback.
*   **Data-Driven Wellness:** To empower users with historical tracking and statistical comparisons, transforming abstract feelings of stress into actionable, trackable data.

## Architecture & Components

The project is built as a modern single-page application using React. The component-driven structure powers a seamless user experience:

*   **Interactive Assessment:** Dedicated form and questionnaire components power the core data-gathering interface to capture baseline user data.
*   **Contextual Analysis:** Chat and email interface modules allow the application to gather deeper, unstructured context about the user's current mental state through simulated conversations or message parsing.
*   **Data Visualization & Results:** Result and comparison views process the analyzed data and present it through intuitive, easy-to-understand metrics and statistical reveals.
*   **Tracking:** History modules enable users to track their stress trends over time, helping them identify long-term patterns.
*   **User Experience:** Core UI elements like dynamic headers, banners, and media players ensure a responsive and accessible interface.

## Setup and Execution

The frontend is bootstrapped within the React application directory. To run the application locally, navigate into the project directory, install the Node dependencies, and start the development server using standard package manager commands (e.g., `npm install` followed by `npm run dev`).
